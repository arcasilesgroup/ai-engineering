# Corpus: ai-council

Reads one specification through five lenses that never see each other, then has them read each
other anonymously to refute what does not hold and to name what all of them missed, then a
chairman writes the page a person reads. It concludes and it never grants.

## Routes here

- "council this spec before I sign it" — the plain trigger: one specification, read by five lenses that do not see each other.
- "read this from several angles" — cost, reversibility, the undecidable path, what is taken on trust, the example nobody wrote.
- "what is this spec missing that nobody noticed" — absence is what this looks for, which is the half a single reader is worst at.
- "pressure-test this before I sign it" — the second round is the pressure: each lens reads the others anonymously and tries to refute them.
- "which of these findings are false alarms" — the cross-read's first question, and the thing independent readers are measured to be worst at.
- "tell me what to do about this spec" — the chairman writes a verdict, a recommendation and one first step, which is the page a person reads.
- "did anybody think about what happens when this is reversed" — the reversibility lens, run as its own reader.
- "is the cost of this written down anywhere" — the cost lens, which reports the absence and the command that shows it.

## Refuses

- "test whether the claims in it are true" — use `/ai-challenge`, because that executes sentences and this asks what is absent.
- "review this diff" — use `/ai-review`, because that judges a change and this reads a specification.
- "write or fix the spec once the lenses report" — use `/ai-spec`, because a council that rewrites the text is no longer reading it.
- "record the decision the council reached" — use `ai-eng decide`, which needs a named person; a verdict here proposes and never grants.
- "mark this specification approved" — refused: it may write a verdict and a recommendation, and there is no field here for an approval, a PASS, a gate result or an accepted risk.
- "have the lenses vote and give me the tally" — refused: there is no vote and no ranking; the second round refutes findings and names what everyone missed.
- "run the lenses in parallel and tell me it was faster" — refused: where the host can it does, where it cannot it runs them in turn, and the file is identical either way.
