01Problem

The pages read like markdown and pay for their own styles

The brainstorm, PRD, recap and research pages use HTML as a styled text file: no diagrams, no tabs, no copy button. Each page rewrites 17 KB of CSS by hand, eight templates hold eight copies that drift, two of them under no gate, and the templates never reach an installed machine.

02Goal

  • one sourceOne edit, every page. A change in brand/ plus gen updates all eight templates; a hand edit turns parity red.
  • zero CSSAgents write content only. They copy a template that is installed on every machine.
  • accessibleWCAG 2.2 AA by test. axe-core finds zero violations on the gallery and every template; every colour pair is declared and measured.
  • everyoneWorks for everyone. Keyboard only, JavaScript off, printed, forced colours, 320 px, 200% zoom, text spacing.
  • one familySame look everywhere. The website imports the same components.css and publishes the gallery.

05Rules

systemHow it is built

  • One source: brand/ holds tokens, components.css and components.js; gen inlines them between markers.
  • Self-contained: inline CSS and JS, no CDN, web font or runtime library; diagrams are inline SVG.
  • Progressive: every component reads with JavaScript off and on paper.
  • Cross-OS: templates join the install payload; font stacks name each OS's own faces.
  • Gallery: brand/gallery.html shows every component live with its markup.

readingHow it reads

  • Ten seconds a section: one plain sentence, then the visual; numbers that matter in bold.
  • Left-aligned prose on the shared left edge; rule 4 and its gate change to match.
  • Owner's components: highlight, chip cards, chip tables, flow trees, verdict cards, before and after, capability matrix, underline tabs.
  • Five chip hues; the word always names the category. One accent bar, on the highlight only.
  • Dark screen theme; a light print palette; no kicker above the title.

blocksNo negotiation

  • A token or component that differs from brand/.
  • Any WCAG 2.2 AA violation; a diagram with no text version.
  • An external script, stylesheet or font.
  • A colour pair a component uses that is not declared and measured.

a11y floorEvery component

  • WAI-ARIA Authoring Practices patterns; native elements first.
  • 44 px touch targets; tables stack under 640 px; tab rows scroll.
  • Forced colours, more contrast and reduced motion honoured; zoom never blocked.
  • No label under 11 px, no running text under 12 px.

06Out of scope

Not in this feature

A light screen theme. A website redesign beyond importing components.css and publishing the gallery. A diagram generator. Mermaid or any runtime library. Rewriting docs/history/. A new skill. Motion beyond state changes. A governed project's own DESIGN.md.
