# Plan — Three-Layer Open-Model Harness (spec-201)

## Summary

Twenty-three decisions across eight concerns. The through-line: make the framework able to
see itself honestly (audit chain, engine identity, cost), then make the surfaces it runs on
actually guarded, then remove the duplication that let all of it rot unnoticed.

Everything below is grounded in direct probing, not inference. Where exploration contradicted
the spec, the correction is called out inline and the spec has already been amended.

## Design

`design-routing: skipped (false-positive keyword match only — "form" and "ui" appear solely
as substrings of format/performs/requires/quirks; spec-201 has no UI surface)`

## Architecture (ad-hoc — extends existing layered + append-only NDJSON telemetry)

**Critical shared context. Every task must respect this map.** There is no new pattern; the
risk is the multi-copy write surface and the sha-pinned hot path.

| Copy family | Paths | Twin rule | Manifest |
|---|---|---|---|
| event/kind authority | `tools/skill_domain/event_schema.py` | authority; `src/ai_engineering/state/event_schema.py` is a 2-line re-export shim (no edit) | none |
| hook canonical | `.ai-engineering/scripts/hooks/_lib/{hook-common,observability,hook_context}.py` | byte-identical to template twin (`cp`) | **sha-pinned** |
| hook template | `src/ai_engineering/templates/.ai-engineering/scripts/hooks/**` | byte-identical to canonical | installer copy |
| pip state | `src/ai_engineering/state/{observability,audit_rollup}.py` | functional-parallel with hook `_lib` (edit both; NOT a byte copy) | none |
| generated mirrors | `.codex/`, `.github/`, `.agents/`, `.opencode/`, `templates/project/**` | regenerated by `scripts/sync_mirrors/` — edit canonical only, then `ai-eng dev sync` | none |

Hard rules, enforced as a gate on every task that touches them:

1. Edit a hook canonical file, then `cp` byte-identical to its template twin in the same task.
2. Any hook byte change needs a manifest regen — but **once, at the end** (Trap 9).
3. Hooks stay stdlib-only; pre-commit under 1s; PreToolUse is the hot path.
4. Introspection and tests use `.venv/bin/python` (bare `python3` is 3.9 here and cannot
   import `ai_engineering`).
5. Never edit a generated mirror directly. Edit canonical, run `dev sync`, commit both.
6. Three kind frozensets exist (`event_schema.py`, `_lib/hook-common.py`,
   `_lib/observability.py`) and a symmetric-difference test enforces equality across all
   three. They move together, in one commit.

### The ten ordering traps

Not style preferences. Four of these red the gate or block the push.

| # | Trap | Consequence if violated |
|---|---|---|
| 1 | `skill_lint` **already blocks** pre-commit (`required=False` covers only the missing-binary branch) | Widening before the corpus fix makes the corpus-fix commit itself unlandable |
| 2 | The generator write site for a deleted tree is still live | `dev sync` silently resurrects every deleted file |
| 3 | Reconciling the engine default to `unknown` before the enum admits it | 100% event loss on every non-Claude harness, not just mislabelling |
| 4 | Escalating the **events** chain doctor check to FAIL | NDJSON is gitignored, so it reds every dev box while CI stays green |
| 5 | Template skill-tree deletion vs `TEMPLATE_SKILL_SURFACES` readers | Two tests error at *collection*, so pre-push `stack-tests` blocks the push |
| 6 | `audit verify --json` returns early before the summary block | `--strict` silently exits 0; the flag ships broken |
| 7 | Root-only `.codex/hooks.json` edit | Byte-identity test against the template reds CI; `dev sync` must be same-commit |
| 8 | `injection-read-guard` needs `matcher: ""`, which a sync test forbids | Guard lands wired-and-dead |
| 9 | Regenerating the hooks manifest per commit | Churn plus a stale-pin window; regen once at the end |
| 10 | Root skill trees are absent from the orphan-sweep list | `dev sync` will never clean them; deletion is always a manual `git rm -r` |

### Wave map

- **Wave A** — Phases 0-2 (audit chain). No twins, no mirrors. Fully independent.
- **Wave B** — Phases 3-4, 8 (event plane, cost). Share `observability.py`; serialize internally.
- **Wave C** — Phases 5-6 (surface collapse, sync targets). Single generator path.
- **Wave D** — Phase 9 (skill_lint corpus). Pure content; can start immediately.
- Serialized after C: Phase 7 (guard planes), Phase 10 (loop-layer content).
- Serialized last: Phases 11-13.
