03Evidence changes advice, not native urgency

Keep the selected inventory

Read signals only after membership is complete. Page selected-item comments safely, retain tombstones only to reconcile totals, and enrich direct parents and the selected team's iterations without adding rows or traversing ancestors and siblings.

Make ordering deterministic

Native critical risk stays first. Current evidenced blockers and commitments overdue, today or within seven UTC calendar days enter an attention group. Native urgency and inventory order resolve ties; unsupported reasons retain native order.

Keep interpretation conservative

Age and comment volume are not urgency. A due date needs current outstanding-work evidence; a forecast needs an explicit commitment. Parent importance and sprint finish do not become inherited deadlines. Custom fields keep unknown semantics.

Follow-up fixes included in the approved result

  1. Accept a comment continuation's canonical project identifier only after matching the already verified scope; reconstruct the scoped request rather than executing a supplied continuation URL.
  2. Retain returned custom-field values and sources when definitions are missing. Validate parent importance per field and expose missing or malformed values as coverage gaps.
  3. Reconcile creation and modification chronology, issue identity and current dependency status. Later withdrawals or resolutions retire old claims; overlapping edits remain questions for clarification.
  4. Recognize renewed confirmations after historical uncertainty without citing superseded positive evidence. Keep unresolved or identity-free evidence conservative.

Provenance is not proof of code behavior

Board fields and comments remain team-reported. Exact source references establish where a claim came from; neither an HTTPS link nor reference validation alone makes prose true or code-verified. Semantic extraction stays in the existing analysis procedure, while code validates claims and selects advice.
