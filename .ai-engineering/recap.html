The milestone's closing report. The contract is .ai-engineering/spec.html (20 gates, all met); the working file is plan.html; this page is the read-back for a human.

01What changed

A repo participates by declaring itself: .ai-engineering/config.toml, existing, parseable and naming its surfaces. That single question is declaration() in src/env.ts, and the chain, the git floor, the verbs and the receipts all ask it — a repo that never declared itself gets allow, exit 0 and not one byte written.

The carrier of each surface now lives where that host reads it: the user's home for Claude Code, OMP, OpenCode, Codex and Pi; the checkout for Cursor and Copilot, whose cloud readers only see the repo. A governed repo went from seven hook files to two.

Files the user also owns are merged by marker and never written whole; the bytes of theirs are reproduced exactly or the merge is refused and said. init.templateDir makes every new clone be born with the git floor, whose shim asks the same gate.

03Proof, not existence

"Not existence" is the milestone's own constraint, in the approved contract: a carrier path is not declared because it exists — it is declared when the host loads it, and OMP is the proof that the two are different things. The carrier ai-engineering shipped for it lived in .agents/hooks/: 1,010 lines, versioned, in every governed repo, hashed in the lock — and read by no OMP code path. doctor's check for it was existsSync(<path>), so the answer was green, every time, in every repo.

That is why every claim in this milestone is a run, not a file: sh scripts/proof-carriers.sh — the OMP carrier loads: the host's own loader discovers it, binds its handlers and blocks an adversarial call; then a real headless session has its fourth identical call denied, with the receipt in the governed repo.

sh scripts/proof-cli-ux.sh — a fresh clone is born with the three shims and commits through the floor; a repo without config.toml gets silence and exit 0; a governed repo without the binary on PATH gets exit 1.

bun test — 179 tests, and bun test tests/arch.spec.ts now reads real imports: the projection used to match no path at all, so every rule passed without looking. Same failure, different layer: a green that cannot fail is not evidence.

04The audit

security/run-2 — eight confirmed findings, all closed here: the loop guard's state file and the verdict cache both keyed their filenames on a host-supplied session id (a traversal that could overwrite the user's own settings); a foreign init.templateDir had its hooks force-written; config --remove deleted a shared settings file whole; the cache lived outside the state the lock owns; restoreTemplateDir deleted a setting instead of restoring it; config --add declared a surface without a carrier; the OMP/Pi carrier ignored PI_CODING_AGENT_DIR; the banner was matched by the word "ai-eng".

06What the loop decided on the way

The gate is asked before the payload is read, because the deny path writes a receipt — in a foreign repo that write was the bug. env became the bottom layer (it may import nothing) and chain may not import surfaces: the structural form of "one gate, and the hot path knows no hosts".

The architecture test was repaired rather than trusted: a green suite over an empty projection is the failure this milestone exists to refuse. The OMP carrier moved to a hook factory at <agentDir>/hooks/pre/, with the bundle dot-prefixed because the host loads every *.ts in that directory as a hook.
