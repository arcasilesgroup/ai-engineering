02 · THE GATES

Three jobs in check.yml

tokens probes the two secrets the repository already carries; sonarcloud runs the suite with an lcov report and scans; snyk tests the dependency set and its SAST. A fork PR is handed no secret, so the two jobs are skipped rather than run green — a missing secret is a visible skip, never a silent pass.

04 · WHAT THE NEW TESTS FOUND

Nine defects, all fixed

  • config --add rewrote an indented enabled by appending a second [surfaces] table — the file stopped parsing and the verb that manages governance turned the repo ungoverned, at exit 0 (a fail-open, §09.2).
  • uninstall (Everything scope) read the declaration after deleting config.toml, leaving a repo-declared surface's machine carrier behind as an orphan.
  • doctor threw ENOENT on a module carrier whose chain bundle was missing — the half-installed state check 11 exists to report.
  • changelogSection's lookahead used $ under the m flag: every real section came back empty, so ai-eng upgrade never showed what was new.
  • commit-msg dropped an active Override-Reason on an already-trailered message.
  • The Claude settings template could not be merged back into itself (inline arrays vs shapeOf): a second install reported "refused" instead of current.
  • init --surface <typo> declared a surface nothing knows, and enforced nothing.
  • The arch check reported ok without reading arch.rules.json — the false green this product exists to refuse.
  • sort() without a comparator on the gc run directories (Sonar's S2871).

06 · SECURITY POSTURE

Compliance, not suppression

Everything the scanners reported is fixed or accepted in the tree with a written reason. No secret is in any diff — the workflow reads secrets.* and never prints it. doctor's adversarial payload is a controlled git commit -n the guard denies. The two rule acceptances above are the only suppressions, and both are named, scoped and argued in source. The remaining gate gap is a measurement artifact, not a weakness: on the first TypeScript analysis the whole tree counts as "new code" against a baseline that only knew the Python line.

07 · WHAT IS LEFT

One condition, and why it reports

Every overall gate condition passes. The one that does not is new-code maintainability (D) — on a branch carrying the first TypeScript analysis, the whole tree is new, so 29 smells count against a baseline that only knew Python: 19 nested ternaries (S3358) and 6 functions over the cognitive-complexity limit (S3776: doctor.ts:runChecks 227, uninstallMain 66, initMain 65, doctor.ts:gc 36, configMain 16, init.ts:52 16). The gate therefore reports rather than blocks (sonar.qualitygate.wait=false), and the README badge carries this same status — nothing is hidden by the flag.
