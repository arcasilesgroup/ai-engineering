The milestone that gives the cycle a graph the code can check. 20 gates, all met; contract .ai-engineering/spec.html, plan plan.html.

01What changed, and why

The blueprint has described an order (§20.1) and a file lifecycle (§21.1) for two versions, and no layer could check either. Twenty skills carried four forward edges in prose; the machinery that did exist — spec open|approve|close, the sha256 pin, doctor --gc — was undiscoverable and, in one case, dead: spec close matched <div class="gate">, markup no spec.html has ever contained, so it verified zero gates and never refused anything. The live proof was in this repo: a completed brainstorm.md with no contract, and doctor printing clean slot beside it.

This milestone makes the graph be the skills. Each SKILL.md declares its own node — lane, condition, artifact, readers, death, successor, and the stops a human speaks for — and six new canon gates enforce the union, so there is nothing central to keep in sync and no router to remember. A milestone now has a base_sha, which is what finally makes "if it touches UI" a question the diff can answer.

05Decisions taken, and what is still open

D-007 A trigger is declared path or judgment. Two of the five can be read from a diff; the other three are questions, and pretending otherwise would have produced a check that passes while the work is missing.

Open, and deliberately not decided here: which surfaces are truly native — each needs a receipt, and Pi already measured as none; and whether [budget] ever becomes a meter rather than a contract the agent keeps at step boundaries.

06Honest notes

One deviation. ai-visual-recap's canonical shape is a BuilderIO agent-native plan built through its block runtime (get-plan-blocks), which this session does not have. This file keeps the substance the skill demands — outcome narrative, file-tree with change flags, the load-bearing diffs with links, the open decisions — as one self-contained document in the blueprint's branding, using <details> where the skill asks for horizontal tabs. The block model was not faked.

One finding during the build. The first version of the trigger declarations was prose in the Trigger when field the evaluator parses as globs — two of the five would have silently never fired. Caught by writing the test first, recorded as D-007, fixed in the canon before the gates were re-run.
