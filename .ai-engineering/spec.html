01Work points

Numbered sections: what must be done. Each point names the gates that prove it done.

01 · The graph stops being prose — and has no hub

Blueprint §20.1 names an order and §21.1 names who writes, who reads and when each artifact dies. Neither is checkable, and nothing in the tree carries it. Every skill declares its own node in a ## Lifecycle block — Lane, Trigger where it is conditional, Writes, Read by, Dies and Next — so the graph is the union of the twenty blocks, in one source, with nothing central to keep in sync.

There is deliberately no router skill. A node that routes would have to restate lanes and triggers that the nodes already declare (drift), and would restate the milestone's state that plan.html already carries (a second copy). The chain runs on Next: alone: a skill ends, names its successor and the condition, and the agent follows it. The human never calls anything.

Proves: G1, G2, G3

02 · The lane is chosen where the classification already happens

ai-brainstorm already classifies every request as spike, bounded or architectural and already stops for approval. It gains the last step: it names the lane out loud, lays out the route that lane implies with the triggers that may add nodes to it, and hands off to the first node. No new entry point, no new ceremony, no hub.

Proves: G5

03 · Milestones get a base, so conditional gates can be evaluated

A conditional gate with no diff to test is decoration. ai-eng spec open records the milestone's base commit in ai-eng.lock; close and doctor evaluate the declared triggers against git diff --name-only <base> and refuse (close) or warn (doctor) when a triggered node left no artifact.

Proves: G7, G9

04 · The death certificate is verified before it is issued

spec close claims "receipts or ABANDON per gate" and matches <div class="gate"> markup that no spec.html has ever contained, so it never blocks: measured on the three archived milestones, zero matches, zero refusals. It parses the real artifact format instead — and re-checks the sha256 pinned at approval before it closes, because a contract edited after the human approved it is not the contract the human approved. An ABANDON line with no reason is refused: an honest exit has to say what it is exiting.

Proves: G8

05 · The civil registrar: orphan artifacts and a gc that collects

A milestone that never opened a contract cannot be closed, so its brainstorm.md is immortal — that is the live zombie in this repo today, and doctor calls the slot clean. Doctor warns on orphan slots, and doctor --gc stops ignoring older_than and keep_runs, stops omitting security/, and stops pretending the citation rule is implemented. Two traps it must not fall into: immunity comes only from a permanent governor, because spec close deletes the milestone's own files and a research cited only by a dead spec would lose its protection the moment it earned it; and the summary it writes into receipts/ must not be counted as a receipt on the next run, which is what summarizeReceipts does today since it parses every .json in the folder.

Proves: G10, G11

06 · ai-goal stops promising a loop that may not exist

Surfaces declare whether they have a native goal loop. native keeps the contract mode; none and unverified run facilitator mode, where the skill walks plan.html one step per turn with the same stops and the same receipts. Pi ships as none (no built-in plan mode or sub-agents); nothing is promoted to native without a receipt.

Proves: G12, G13, G14

07 · The human speaks words; the agent runs the binary

A governed cycle that ends by asking the person to type ai-eng spec approve is not an agentic product — it is a CLI with a chat window in front. Every human stop is declared by the skill that owns it as a mapping from words ("approve", "ok", "go", "close") to the command the agent runs underneath, and a canon gate fails when a stop is missing either half. Approving stays human-only: the word is the gate, the command is the pencil, and the agent never runs it on its own initiative.

And the word has to be about the thing. Each stop also declares Confirms: — the object the human is approving — because the cheapest way to break this design is for the agent to read a bare "ok" meant as acknowledgment of a proposal as authorization for it. The rule is: state what you are about to run and what it pins, ask once, and treat a word that answers a different sentence as no answer at all. An agent that decides for itself that the human said yes is approving on its own initiative with extra steps.

Proves: G4, G17

08 · The drifts stop contradicting the code

Blueprint §13 calls Pi skills-only while plugin.pi.ts.tpl governs it in-process; the config template offers a pi-zed surface that does not exist; the planted AGENTS.md never mentions the cycle, so no agent discovers it exists.

Proves: G15, G16, G17

09 · The milestone closes like any other

Regenerated payload, the full suite green, and the recap that step 12 has never once produced in this repo.

Proves: G18, G19, G20

03Constraints & contracts

No hub, no new node. The graph is the twenty ## Lifecycle blocks and nothing else: a skill added without a block fails the canon, and a Next: naming a skill that does not exist fails the canon. If a single human-readable page is ever needed, it is a doctor flag that prints the union — never a skill to remember.

The ratchet is one-way. A lane can be upgraded mid-milestone (hidden complexity discovered), never downgraded in silence; a downgrade is an ABANDON line with a reason, or a DECISIONS.md block.

Light lane is legal, not a loophole. ai-brainstorm already tells spike and bounded work to skip the spec file; the graph makes that path explicit instead of contradicting §20.1. What changes is that the artifact still dies.

No new CLI verb. base_sha rides in ai-eng.lock and trigger evaluation rides inside spec close and doctor — both already exist (§21.5: doctor validates, spec runs, nobody adds a verb).

Budget stays a contract, not a meter. [budget] is read and honoured by the agent at step boundaries; nothing in the binary measures tokens. Declared here so it is not read as an implemented guard (§12.1).

Immunity needs a permanent governor. spec.html, plan.html and brainstorm.md die at close, so a research cited only there loses its protection the moment it earns it. Only DECISIONS.md, arch.rules.json and NOTICE confer immunity, and gc's citation grep scans exactly that set — the rule lives in the code that enforces it, not in a note that claims it.

Non-goals: no per-surface goal-loop detection at runtime (a declared capability, verified by receipt, not a probe); no rewiring of ai-design's inner router, which keeps routing design skills while the Next: chain carries the milestone.
