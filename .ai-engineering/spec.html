02 · init: boosters + re-init paths + frame continuity

Surface hints mapped from surfaces.json (tier + can.*), never hardcoded. Boosters offered through groupMultiselect (5 groups, 14 items, src/boosters.ts prints commands, never installs; probe confirmed headers are non-selectable, no tab-jump line). Git-init confirm gets initial=true. Re-init offers three paths (update / config / exit), not two. Scaffold checklist renders inside the frame; bootstrap note when src/ is absent; the two human steps close as outro. UI language: English. Versions always printed from VERSION (2.0.0), never hardcoded.

Proves: G3, G4

03 · doctor: frame + canon check root cause + assets-outdated

Contextual intro (repo · runtime · version). Check 4 (canon+lock) currently reports 0 assets verified because it filters lock.assets by skills/ paths that the repo lock never contains; rewrite it to verify the global canon against the binary's embedded assets. New check: lock.version ≠ VERSION → WARN pointing at ai-eng update. Checks render through ui.*; colored summary line.

04 · update: plan → confirm → write

Compute the sync plan before writing anything: list "What needs to sync", conflicts offer keep-yours (default) / take-new / show-diff, Apply confirm (Yes+commit / Yes / No), commit chore(ai-eng): assets → VERSION. Happy path (nothing to sync): one line + doctor pointer, exit 0, no prompts, lock untouched. Fix inline require() usage in update.ts.

Proves: G7, G8

05 · upgrade / config / uninstall + version notice

upgrade: frame, inline changelog when CHANGELOG.md carries the section (else URL), fix print-command bug (always prints bun). config: installed/not-installed hints, thresholds note. uninstall: exact §14.5 flow with outro. cli.ts: maybeNotice() — 24h-cached version check, silent on failure, one line at the end of init/doctor/update, opt-out via notices=false or AI_ENG_NO_UPDATE_NOTICES. 03Constraints & contracts

Data contracts: ui.ts exports frame(), ok(), warn(), fail(), info(), summary(); command modules take presentation from ui.ts only. branding.ts keeps showLogo for --help/--version.

The lockfile is the ownership record: update writes only what ai-eng.lock lists; anything else is the user's.

Non-goals: machine verbs (chain/git/wrap/spec) keep byte-stable stdout (§07 machine contract); no new dependencies (cap of 3). Version display always from src/version.ts — the 0.13.0 mockup numbers are obsolete examples.

Why the alternative was refused: live in brainstorm.md @ git b3d70782 (research link above), not in a new DECISIONS block.
