# Code of Conduct

## Our standard

Everyone participating in the ai-engineering project — issues, pull requests,
discussions, chat — agrees to treat people with respect. We are professionals
building tooling for professionals; the bar is simple:

- Be respectful and constructive. Critique code, not people.
- Assume good faith; disagree with evidence, not volume.
- No harassment, discrimination, personal attacks, or trolling.
- Keep discussions on-topic; spam and self-promotion are off-limits.

## Scope

This applies to the project's repositories, issue trackers, pull requests, and
any official project communication channel. It also applies when representing
the project in public spaces.

## Enforcement

Report violations to the maintainers: **conduct@arcasiles.group** (or, for
sensitive matters, privately to any maintainer via GitHub). Reports are
reviewed within 72 hours; the maintainers may warn, mute, or ban participants
from project spaces. Repeated or severe violations result in a permanent ban.

Maintainers who violate this code face the same enforcement, without exception.

## Attribution

This Code of Conduct follows the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/) (v2.1), adapted
for brevity.
