
 Usage: ai-eng risk list [OPTIONS]

 List risk-acceptance decisions filtered by status/severity/expiry.

╭─ Options ────────────────────────────────────────────────────────────────────╮
│ --status                TEXT     Filter by status: active, expired,          │
│                                  superseded, revoked, remediated, all.       │
│                                  [default: active]                           │
│ --severity              TEXT     Filter by severity (critical, high, medium, │
│                                  low).                                       │
│ --expires-within        INTEGER  Only show decisions expiring within N days  │
│                                  (active only).                              │
│ --format                TEXT     Output format: table, json, markdown.       │
│                                  [default: table]                            │
│ --help                           Show this message and exit.                 │
╰──────────────────────────────────────────────────────────────────────────────╯
