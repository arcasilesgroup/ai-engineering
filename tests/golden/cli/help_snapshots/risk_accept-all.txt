
 Usage: ai-eng risk accept-all [OPTIONS] FINDINGS_PATH

 Bulk-accept all findings in a ``gate-findings.json`` document.

╭─ Arguments ──────────────────────────────────────────────────────────────────╮
│ *    findings_path      PATH  Path to a ``gate-findings.json`` document (v1  │
│                               or v1.1).                                      │
│                               [required]                                     │
╰──────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────╮
│ *  --justification        TEXT  Why this batch is accepted (>=10 chars).     │
│                                 [required]                                   │
│ *  --spec                 TEXT  Spec that owns this acceptance batch.        │
│                                 [required]                                   │
│ *  --follow-up            TEXT  Plan to remediate before expiry. [required]  │
│    --max-severity         TEXT  Skip findings stricter than this (default:   │
│                                 accept all).                                 │
│    --expires-at           TEXT  ISO-8601 expiry override per-finding.        │
│    --dry-run                    Print the planned batch without persisting.  │
│    --accepted-by          TEXT  Actor; defaults to ``git config              │
│                                 user.email``.                                │
│    --help                       Show this message and exit.                  │
╰──────────────────────────────────────────────────────────────────────────────╯
